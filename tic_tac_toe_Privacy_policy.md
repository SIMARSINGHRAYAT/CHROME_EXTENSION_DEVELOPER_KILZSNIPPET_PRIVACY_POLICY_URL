# Privacy Policy for Tic Tac Toe Pro

**Effective Date:** July 2026  
**Extension Name:** Tic Tac Toe Pro

## Overview
Tic Tac Toe Pro is a lightweight browser extension that allows users to play Tic Tac Toe directly inside the browser popup. The extension is designed to run fully client‑side and offline, without collecting or transmitting any personal data.

## Data Collection
- The extension does **not** collect, transmit, or share any personal information, browsing data, or identifiers.
- The only data stored is the local scoreboard (Player X wins, Player O wins, and Draws).
- This data is stored using `chrome.storage.local` and remains entirely on the user’s device.

## Data Usage
- Stored scores are used solely to persist game results between sessions.
- No data is sent to external servers or third parties.

## Permissions
- The extension requests the `storage` permission to save and retrieve scoreboard values.
- No other permissions are requested or required.

## Remote Code
- The extension does not use any remote code, external scripts, or analytics.
- All HTML, CSS, and JavaScript files are packaged within the extension.
