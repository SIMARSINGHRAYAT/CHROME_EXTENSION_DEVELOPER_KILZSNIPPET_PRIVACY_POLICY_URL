# Privacy Policy

**Last Updated:** July 6, 2026

## Endless Runner Chrome/Edge Extension

Endless Runner is designed with user privacy in mind. The extension
operates entirely on your device and does not collect, transmit, or
share any personal information.

## Information We Collect

This extension **does not collect**:

-   Personal information
-   Browsing history
-   Website content
-   Login credentials
-   Financial information
-   Device identifiers
-   Location data
-   Contact information
-   Analytics or telemetry data

## Local Storage

The extension uses the browser's local storage API only to save
game-related data, such as:

-   High score
-   Basic game preferences (if enabled)

This information is stored **locally on your device** and is never
transmitted to any external server.

## Network Communication

The extension does **not**:

-   Connect to external servers
-   Download or execute remote code
-   Display advertisements
-   Use analytics services
-   Track user activity
-   Send data to third parties

All game assets and code are packaged within the extension.

## Permissions

The extension requests only the permissions necessary for its
functionality.

-   **storage** --- Used solely to save and retrieve local game data
    such as the player's high score and settings.

## Third-Party Services

Endless Runner does not use any third-party analytics, advertising,
tracking, or cloud services.

## Children's Privacy

The extension does not knowingly collect personal information from
anyone, including children.

## Changes to This Privacy Policy

If this privacy policy changes in the future, the updated version will
be published with the extension listing.

## Contact

If you have any questions regarding this Privacy Policy, please contact
the extension developer through the Microsoft Edge Add-ons Store or the
Chrome Web Store listing, if available.
