# Privacy Policy
## PNG Resizer
**Last Updated:** June 10, 2026

---

## Overview

PNG Resizer is a browser extension that allows users to resize PNG images to custom dimensions directly within their browser.

We are committed to protecting your privacy. This extension is designed to operate entirely on your device and does not collect or transmit personal information.

---

## Information We Collect

PNG Resizer does **not collect, store, transmit, or share any personal data**.

The extension only processes the PNG image file that you manually select for resizing. This processing happens locally within your browser.

We do not collect:

- Personal information  
- Browsing history  
- Website data  
- Analytics data  
- Usage statistics  
- Device information  

---

## How the Extension Works

When you upload a PNG image:

1. The image is read locally using your browser’s FileReader API.
2. The image is decoded and resized using the HTML Canvas API.
3. The resized image is generated and made available for download.

All processing happens entirely on your device.

No image data is uploaded to any server.

---

## Data Storage

PNG Resizer does not permanently store your images or resized files.

All processing is temporary and occurs within the current browser session. Once the extension popup is closed, no image data is retained by the extension.

---

## Permissions

PNG Resizer requests only the minimum permissions necessary for functionality.

If the extension uses the `downloads` permission:
- It is used solely to allow users to save the resized PNG image to their device.
- It does not access browsing activity or external websites.

The extension does not request host permissions or access to webpage content.

---

## Remote Code

PNG Resizer does not use remote code.

All JavaScript, HTML, CSS, and image-processing logic are fully packaged within the extension.  
There are no external scripts, no remote APIs, and no dynamically loaded code.

---

## Third-Party Services

PNG Resizer does not use:

- External APIs  
- Analytics tools  
- Advertising networks  
- Tracking technologies  
- Cloud storage services  

---

## Data Sharing

We do not sell, share, rent, or transfer any user data.

The developer has no access to the images you upload or resize.

---

## Children's Privacy

Since PNG Resizer does not collect personal data, it does not knowingly collect information from children or any users.
