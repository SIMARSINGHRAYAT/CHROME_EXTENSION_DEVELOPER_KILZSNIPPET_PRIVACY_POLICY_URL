# Privacy Policy
## URL to QR
**Last Updated:** June 10, 2026

---

## Overview

URL to QR is a simple browser extension that allows users to generate QR codes from any valid URL.  

Your privacy is important to us. This extension is designed with a strong commitment to user privacy and data security.

---

## Information We Collect

URL to QR does **not collect, store, transmit, or share any personal data**.

The extension only processes the URL that a user manually enters for the purpose of generating a QR code. This processing happens entirely within the user’s browser.

We do not:

- Collect personal information
- Track user activity
- Store browsing history
- Access website content
- Use analytics or tracking tools

---

## How the Extension Works

When a user enters a URL:

1. The URL is processed locally within the browser.
2. A QR code is generated using locally bundled code.
3. The user can download or copy the QR code image.

No data is sent to external servers.

All QR code generation happens entirely on the user's device.

---

## Permissions Used

### clipboardWrite

This permission is used only when the user chooses to copy the generated QR code image to their clipboard.  

The extension:
- Does not read clipboard contents  
- Does not monitor clipboard activity  
- Only writes to the clipboard after explicit user interaction  

No other sensitive permissions are requested.

---

## Data Storage

URL to QR does not permanently store user data.  

If temporary processing occurs (for QR code generation), it remains within the browser session and is not saved or transmitted externally.

---

## Third-Party Services

URL to QR does not use:

- External APIs  
- Remote scripts  
- Analytics platforms  
- Advertising networks  
- Tracking services  

All functionality is self-contained within the extension package.

---

## Data Sharing

We do not sell, share, or transfer any user data to third parties.

The developer has no access to user-entered URLs or generated QR codes.

---

## Children's Privacy

This extension does not collect personal information from anyone, including children. It is safe for general audiences.
