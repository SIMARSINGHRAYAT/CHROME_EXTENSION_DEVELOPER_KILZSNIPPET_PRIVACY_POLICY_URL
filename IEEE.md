# Privacy Policy
## Scholar Reference Finder
**Last Updated:** June 16, 2026

---

## Overview

Scholar Reference Finder is a browser extension that allows users to search for academic publications using keywords and retrieve formatted references in IEEE citation style.

We are committed to protecting user privacy. This extension is designed to operate with minimal data usage and does not collect or store personal information.

---

## Information We Collect

Scholar Reference Finder does **not collect, store, transmit, or sell personal data**.

The extension processes only:

- The keyword or search query entered by the user
- The number of references requested

This information is used solely to fetch academic publication metadata from publicly available scholarly APIs.

We do not collect:

- Personal identification information
- Browsing history
- Website content
- Account credentials
- Device information
- Analytics or tracking data

---

## How the Extension Works

When a user enters a keyword and initiates a search:

1. The keyword is sent to approved academic metadata APIs (such as Crossref, OpenAlex, or Semantic Scholar).
2. Publicly available publication metadata is retrieved.
3. The extension formats the results into IEEE citation style.
4. Results are displayed inside the extension popup.

The extension does not scrape websites and does not access restricted databases.

---

## Data Storage

The extension does not permanently store search queries or retrieved references.

If the `storage` permission is used, it is only for saving user interface preferences (such as selected number of references). No personal data is stored.

All searches are processed in real time and are not retained by the developer.

---

## Third-Party Services

The extension retrieves academic metadata from publicly accessible APIs, which may include:

- Crossref REST API  
- OpenAlex API  
- Semantic Scholar API  

These services operate independently and have their own privacy policies. The extension does not control how these services handle requests.

No analytics tools, advertising networks, or tracking services are used.

---

## Data Sharing

We do not:

- Sell user data  
- Share personal data  
- Store search histories  
- Track user behavior  

The developer does not have access to individual search queries.

---

## Permissions

The extension requests only the minimum permissions required to:

- Perform network requests to approved academic APIs
- Optionally store user preferences (if storage is used)

The extension does not request access to browsing history, tabs, or webpage content.

---

## Remote Code

All scripts and logic are packaged within the extension bundle.

The extension does not use remote executable code, dynamically loaded scripts, or eval().

---

## Children's Privacy

Since no personal data is collected, the extension does not knowingly collect information from children or any users.
